# Como gerar o SleepTimer.exe

## Requisitos
- Node.js 18+ instalado (https://nodejs.org)

## Passos

1. Extraia o ZIP em qualquer pasta
2. Abra o terminal nessa pasta e rode:

```
npm install
npm run build
```

3. O arquivo `SleepTimer.exe` será gerado em `dist/`

## Rodar sem compilar (modo dev)
```
npm install
npm start
```
